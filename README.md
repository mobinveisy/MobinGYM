# MobinGYM 🏋️

**وب‌اپ اختصاصی فارسی بدنسازی و تغذیه** — یک فایل HTML، بدون نیاز به Node.js، نصب پکیج، دیتابیس یا فرایند Build.

## انتشار از گوشی روی GitHub Pages

1. وارد GitHub شوید و از **New repository** یک ریپازیتوری مثل `MobinGYM` بسازید. برای استفاده از GitHub Pages طبق محدودیت پلن/ریپو، عمومی‌بودن ریپو را بررسی کنید.
2. از مرورگر گوشی صفحه ریپازیتوری را باز کنید. **Add file → Upload files** را بزنید.
3. فایل `index.html` را از این بسته انتخاب کنید. حتماً نام فایل دقیقاً `index.html` و در **ریشه ریپازیتوری** باشد، نه داخل یک پوشه.
4. گزینه **Commit changes** را بزنید.
5. از **Settings → Pages → Build and deployment**، گزینه **Deploy from a branch** را انتخاب کنید.
6. Branch را روی **main** و Folder را روی **/(root)** بگذارید؛ سپس Save کنید.
7. بعد از انتشار، آدرس سایت معمولاً به این شکل است:
   `https://YOUR-USERNAME.github.io/MobinGYM/`
8. در مرورگر گوشی می‌توانید **Add to Home Screen** را بزنید تا آیکن وب‌اپ به صفحه اصلی اضافه شود.

در بعضی نمایشگرهای موبایل لازم است حالت **Desktop site** مرورگر را فعال کنید تا منوی Settings/Pages در GitHub راحت‌تر دیده شود.

## قابلیت‌ها

- رابط فارسی راست‌به‌چپ با تم مشکی/آبی گرادیانی و افکت‌های شیشه‌ای
- محیط باشگاه سه‌بعدی با **Three.js**، وسایل باشگاه، هالتر و دمبل، آدمک‌های متحرک، واکنش افتادن و بلندشدن با کلیک
- لوگوی MobinGYM و افکت‌های حرکتی
- ۴ برنامه تمرین: بالاتنه A، پایین‌تنه A، بالاتنه B، پایین‌تنه B
- ثبت تیک هر ست، وزنه و تکرار واقعی + تایمر استراحت خودکار
- پیشنهاد خودکار جلسه بعدی بر اساس جلسه پایان‌یافته، با امکان تغییر دستی
- انتخاب و جابه‌جایی چهار روز تمرین در هفته
- نمایش روز، هفته، تاریخ شمسی و تقویم فعالیت‌ها
- نمودار تغییر وزن و ثبت اختیاری دور کمر
- برنامه غذایی نمونه ایرانی با جایگزین‌ غذاها، کالری و ماکروهای تقریبی، ثبت وعده و آب روزانه
- ذخیره خودکار اطلاعات در `localStorage` مرورگر برای هر تاریخ
- خروجی و بازیابی فایل پشتیبان JSON
- طراحی ریسپانسیو برای موبایل و دسکتاپ

## نکات مهم درباره حفظ اطلاعات

- **سوابق در مرورگر همان دستگاه و همان دامنه ذخیره می‌شوند**؛ انتشار کد در GitHub آنها را در GitHub یا فضای ابری ذخیره نمی‌کند.
- اطلاعات برنامه، غذا، ست‌ها و اندازه‌گیری‌ها در `localStorage` هستند؛ با رفرش معمولی سایت پاک نمی‌شوند.
- حذف داده‌های سایت، حالت ناشناس، تغییر گوشی/مرورگر/دامنه می‌تواند اطلاعات را از بین ببرد.
- برای جلوگیری از ازدست‌رفتن سوابق، از بخش **تنظیمات → دانلود بکاپ JSON** خروجی بگیرید و در جای امن مثل فضای ابری شخصی نگه دارید.
- روی دستگاه جدید از همان بخش **بازیابی بکاپ** را بزنید.
- **همگام‌سازی ابری خودکار بین دستگاه‌ها هنوز وجود ندارد.** برای آن به سرویس احراز هویت و پایگاه داده (مثلاً Supabase یا Firebase) نیاز است.

## اتصال‌های خارجی

سه‌بعدی از نسخه مشخص و تثبیت‌شده Three.js (`0.180.0`) روی دو CDN (`jsDelivr` و `unpkg`) بارگذاری می‌شود؛ فونت Vazirmatn نیز از Google Fonts بارگذاری می‌شود. در شبکه‌هایی که این سرویس‌ها مسدود باشند، رابط تمرین و تغذیه همچنان کار می‌کند، اما نمای سه‌بعدی جای خود را به تصویر برداری ساده می‌دهد و فونت جایگزین سیستم نمایش داده می‌شود.

## نکات علمی

- تقسیم‌بندی تمرینی چهارروزه برای سابقه تمرینی غیرپیوسته طراحی شده و باید از دو هفته ابتدایی با حجم و فشار کمتر شروع شود.
- انیمیشن‌های حرکات **شماتیک** هستند، نه آموزش تشریحی تکنیک؛ حرکات سنگین با نظارت مربی و متناسب با سابقه آسیب اجرا شوند.
- برنامه غذایی صرفاً نمونه است، مقادیر غذا و درشت‌مغذی‌ها تخمینی‌اند؛ دریافت انرژی واقعی با روند وزن و شرایط جسمی تنظیم شود.
- در صورت بیماری زمینه‌ای یا دارو، رژیم و تمرین را با پزشک/متخصص واجد صلاحیت تطبیق دهید.

## ویرایش سایت

تمام ظاهر، منطق جاوااسکریپت و داده‌های تمرین داخل فایل `index.html` قرار دارند. می‌توانید فایل را در خود GitHub ویرایش کنید. برای تغییر حرکات، آرایه‌ی `plans`، برای وعده‌ها `MEALS`، و برای برنامه‌ پیش‌فرض روزهای هفته `BASE.schedule` را ویرایش کنید.
