# MobinGYM 2.0 — اپ شخصی باشگاه

این نسخه برای انتشار روی GitHub Pages ساخته شده و با فایل‌های استاتیک اجرا می‌شود.

## انتشار با گوشی روی GitHub

1. فایل `MobinGYM-v2-GitHub-Pages.zip` را دانلود و در گوشی Extract کن.
2. وارد ریپازیتوری `mobinveisy/MobinGYM` شو.
3. اگر `index.html` قدیمی داری، با نسخه جدید جایگزین کن. این بسته **۸ فایل اصلی** دارد؛ همه را **در ریشه همان ریپازیتوری** بگذار، نه در یک پوشه اضافی:
   - `index.html`
   - `style.css`
   - `styles-v2.css`
   - `app.js`
   - `manifest.webmanifest`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
4. با **Add file → Upload files** همه فایل‌ها را انتخاب کن (و در صورت وجود نسخه قدیمی، جایگزینی را تایید کن). سپس **Commit changes**.
5. در **Settings → Pages** گزینه `Deploy from a branch`, شاخه `main`, پوشه `/(root)` را فعال کن.
6. سایت: https://mobinveisy.github.io/MobinGYM/
7. بعد از انتشار در Chrome (Android)، از گزینه **Install app** یا دکمه نصب داخل سایت استفاده کن. مرورگر ممکن است پس از تعامل اولیه پیشنهاد نصب را نشان دهد.

## امکانات

- رابط فارسی با قلم Vazirmatn، تم مشکی/آبی، خط نئونی و ترنزیشن صفحات
- لوگوی دمبل متحرک و لودینگ دمبل
- باشگاه Three.js با آینه واقعی مبتنی بر `Reflector`، دستگاه‌ها و ورزشکارهای تعاملی. برای بارگذاری Three.js به اینترنت نیاز است؛ اگر CDN قطع باشد SVG متحرک جایگزین نمایش داده می‌شود.
- برنامه Upper/Lower با ست‌های واقعی، ثبت سریع یک‌لمسی، اصلاح وزن/تکرار، تایمر استراحت
- تاریخ و تقویم شمسی، روزهای قابل جابه‌جایی، سوابق ثبت‌شده و نمودار واقعی وزن/دور کمر
- تغذیه با میزان واقعی هر وعده، غذای دلخواه، پروتئین، کالری، آب و کافئین
- پخش‌کننده موسیقی محلی (IndexedDB؛ بدون آپلود فایل موسیقی روی سرور)
- PWA: manifest، آیکون ۱۹۲/۵۱۲ و service worker برای نصب و کش پوسته برنامه
- تنظیم یادآور محلی هنگام باز/فعال بودن برنامه و دسترسی به اعلان‌های مرورگر

## نکات ضروری

- **اطلاعات قبلی پاک نمی‌شوند**: این نسخه همچنان از کلید `mobingym_v2` مرورگر استفاده می‌کند؛ البته باید همان دامنه، دستگاه و پروفایل مرورگر را نگه داری.
- برای امنیت داده‌ها از بخش **تنظیمات → دانلود بکاپ JSON** نسخه پشتیبان بگیر. موسیقی‌ها داخل بکاپ JSON قرار نمی‌گیرند.
- GitHub Pages به تنهایی سرویس Push سمت سرور ندارد؛ برای ارسال اعلان زمان‌بندی‌شده در حالی که برنامه کاملاً بسته است، به Push sender و VAPID مثل Cloudflare Worker نیاز است. Service worker دریافت Push را پشتیبانی می‌کند اما سرویس ارسال در این نسخه وجود ندارد.
- برای نصب اپ حتماً سایت را از `https://` باز کن؛ فایل‌های HTML روی گوشی به تنهایی PWA نصب نمی‌شوند.
- انیمیشن درون کارت‌های حرکات **شماتیک** است؛ برای آموزش واقعی فرم، از لینک ویدیوی آموزشی هر حرکت استفاده کن. این برنامه تشخیص پزشکی یا مربی خصوصی نیست.
- اعداد غذا و کافئین تقریبی هستند و به مقدار واقعی و نوع محصول بستگی دارند.
